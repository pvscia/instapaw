Simple complaint website # Simple Complaint Website

A simple complaint management website with user authorization, built using **Spring Boot** for the backend and **React.js** for the frontend.

## Features

- User authentication and authorization
- Submit complaints
- View complaint status
- Basic role-based access control
- RESTful API integration between backend and frontend

## Tech Stack

### Backend
- Java 8
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL (or other relational database)

### Frontend
- React.js
- Axios
- Bootstrap / CSS
